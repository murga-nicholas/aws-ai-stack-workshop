# AWS AI stack workshop: full text

> The complete text of the DataArt workshop "AWS AI stack" (Mykola Murha, 2026-10-05): all 55 slides of `aws_ai_stack.pptx` in order, each with its agenda segment, time window and speaker notes, followed by the repository README. Slides 1-44 are presented in 60 minutes; slides 45-55 are a take-home appendix.

This file exists because the deck is a binary PowerPoint file that language models and search tools cannot read. It is generated from the repository by `deck/build_llms.py`; the short index is [llms.txt](https://raw.githubusercontent.com/murga-nicholas/aws-ai-stack-workshop/main/llms.txt). The deck itself is generated from data: the slides are declarative YAML in `deck/content/`, recorded demo evidence is in `deck/facts.json`, lifecycle facts are in `data/lineage.yaml` and the presenter script is `deck/speaker_notes.md`. If this file and those sources disagree, the sources win.

Product names, statuses, dates and prices are a dated snapshot read on 2026-10-05. In particular: Amazon Bedrock Agents is called "Agents Classic" since 2026-06-30 and closed to new customers on 2026-07-30; Amazon Kendra and Amazon Q Business closed to new customers on the same date; and "AgentCore" on the slides means Amazon Bedrock AgentCore, a family of separately usable building blocks rather than one service.
